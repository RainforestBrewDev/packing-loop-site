# Packing Loop public pages

Public English and Japanese information for Packing Loop / もちものループ by RainForestBrewDev.

- [Privacy policy](https://rainforestbrewdev.github.io/packing-loop-site/)
- [Closed-test participation guide](https://rainforestbrewdev.github.io/packing-loop-site/testing/)

This repository contains only the public website. Android application source code is managed separately.

## Publishing

GitHub Pages publishes the root of the `main` branch. Edit `index.html` for the privacy policy or `testing/index.html` for the participant guide, then push to `main`.

Both pages use relative links so they work under the GitHub Pages project path. `.nojekyll` keeps this a plain HTML site.
